


# Flow Productivity App

A simple, sleek productivity app made with plain HTML, CSS and JavaScript.

## Features
1. Task manager with add, complete and delete
2. Progress tracker
3. 25 minute focus timer
4. Quick notes with automatic browser saving
5. Daily focus goal
6. Responsive sidebar navigation
7. LocalStorage so tasks and notes survive refreshes
